# عالم إيسيكاي

صفحة ويب واحدة لقراءة رواية «عالم إيسيكاي»: خريطة العالم، وتاريخ الممالك الأربع من عام 300 إلى 1100.

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة (يحتاج اتصال إنترنت لتحميل خطوط Google Fonts).

## النشر على GitHub Pages
1. ارفع كل محتويات هذا المجلد إلى مستودع جديد.
2. من Settings ← Pages اختر Branch: `main` والمجلد `/ (root)`.
3. الرابط يظهر بعد دقيقة تقريباً.

## الهيكل
- `index.html` — الصفحة والنص كاملاً
- `css/style.css` — التصميم
- `js/main.js` — الفهرس وتكبير الخريطة وشريط التقدم
- `images/` — الخريطة والخلفيات والشعار
- `story/` — ملفا القصة الأصليان (للرجوع إليهما)
